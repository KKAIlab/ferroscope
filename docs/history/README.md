# Development history

FerroScope was built in review rounds. In each round an independent reviewer looked for places where the site claimed more than its evidence supported, and the next round fixed them and added a regression test for each fix. These files are the record of that process. The code and data do not depend on them.

| File | What it is |
|---|---|
| `CLAUDE_CODE_HANDOFF.md` | The original round-1 build plan (superseded) |
| `DELIVERY_AUDIT_FOR_CODEX.md` | Round-1 delivery audit submitted for independent review |
| `HANDOFF.md`, `HANDOFF_ROUND3.md` | Review findings and the specification for the next round |
| `CODEX_REVIEW_ROUND2.md` … `CODEX_REVIEW_ROUND5.md` | Independent reviews of each delivery |
| `DELIVERY_AUDIT_ROUND2.md` … `DELIVERY_AUDIT_ROUND9.md` | For each round: what changed, how it was tested, and what remains open |

A summary of each release is in [`../CHANGELOG.md`](../CHANGELOG.md).
